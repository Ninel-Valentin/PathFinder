
# Pathfinding application
#### -JAVA

**Notes**
- This project is a new improved version of a scratched passion project from 2020, ultimately redeveloped for a university project in 2024.

**Description**

1. A desktop application which displays a custom free-draw or grid-based canvas, where you can draw a map made out of nodes/points and weighted(___optional___) edges/connections.
2. You can select a starting and ending point and a pathfinding algorithm to ultimately see the result.
3. The ability to save/load files is present, as well as loading certain templated maps to properly demonstrate certain algorithms.
